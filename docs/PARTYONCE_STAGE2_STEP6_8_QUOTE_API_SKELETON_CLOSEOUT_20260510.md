## 3. Accepted API Surface

Accepted Quote API skeleton endpoints:

```text
POST /api/quotes
GET /api/quotes
GET /api/quotes/{quote_id}
PATCH /api/quotes/{quote_id}
```

Accepted behavior:

```text
Quote must be created from a persistent Lead
Quote creation requires admin access
Quote creation validates the Lead exists
Quote creation creates status=draft
Quote creation writes to the quotes table
Quote creation updates the Lead to converted_to_quote in the same transaction
Quote list/detail/update require admin access
PATCH can set draft / sent / accepted / rejected / expired
PATCH converted_to_order is blocked in this stage
```
